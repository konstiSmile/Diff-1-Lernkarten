Install iPhone

Safari
  1. Link in Safari öffnen (nicht im Browser von WhatsApp oder Instagram).
  2. Unten auf Teilen tippen ⇪ (Quadrat mit Pfeil nach oben).
  3. „Zum Home-Bildschirm“ wählen (ggf. unter „Mehr“), dann „Hinzufügen“.
  4. Icon antippen: Die App öffnet im Vollbild.
Wichtig: Einmal mit Internet vom Home-Bildschirm öffnen, danach läuft sie auch im Flugmodus.

Install Android

Chrome
  1. Link in Chrome öffnen.
  2. Oben rechts auf das Menü tippen ⋮ (drei Punkte).
  3. „App installieren“ oder „Zum Startbildschirm hinzufügen“ wählen und bestätigen.
  4. Icon antippen: Die App öffnet im Vollbild.
Wichtig: Einmal mit Internet öffnen, dann geht es offline. Samsung Internet: Menü, „Seite hinzufügen zu“, „Startbildschirm“.
