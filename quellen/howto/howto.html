Install iPhone

Safari
  1. Link in Safari öffnen (nicht im Browser von WhatsApp, Instagram oder Mail).
  2. Unten auf das Teilen-Symbol tippen ⇪ (Quadrat mit Pfeil nach oben).
  3. Nach unten scrollen und „Zum Home-Bildschirm“ wählen, ggf. unter „Mehr“.
  4. Oben rechts auf „Hinzufügen“ tippen. Das Icon liegt jetzt auf dem Home-Bildschirm.
  5. Icon antippen: die App öffnet im Vollbild, ohne Browserleiste.
Wichtig: Öffne die App einmal mit Internet vom Home-Bildschirm. Danach läuft sie auch im Flugmodus.

Install Android

Chrome
  1. Link in Chrome öffnen.
  2. Oben rechts auf das Menü tippen ⋮ (drei Punkte).
  3. „App installieren“ oder „Zum Startbildschirm hinzufügen“ wählen.
  4. Mit „Installieren“ bzw. „Hinzufügen“ bestätigen. Das Icon erscheint auf dem Startbildschirm und in der App-Liste.
  5. Icon antippen: die App öffnet im Vollbild.
Wichtig: Einmal mit Internet öffnen, dann geht es auch offline. Bei Samsung Internet: Menü, „Seite hinzufügen zu“, „Startbildschirm“.
Offline nutzbarNach dem ersten Öffnen mit Internet brauchst du kein Netz mehr.
UpdatesNeue Karten kommen automatisch: App zweimal mit Internet öffnen.

Tests: Einstellungen

bei Querschnitt und Psycho2

Im Test-Menü wählst du oben die Fragen pro Runde (5, 10 oder alle) und tippst dann eine Testart an. Jede Kachel zeigt deinen Bestwert.

Falsch beantwortete Fragen werden gemerkt. „Falsche Fragen wiederholen“ übt genau diese, bis du sie richtig hast.

Tests

Die vier Abfragearten

Alle Tests geben dir eine Erklärung zur richtigen Lösung.

1 · Multiple Choice

Vier Antworten, eine stimmt

Welche Bedingung gilt an einer inneren Extremstelle?
Agrad f(a) = 0
Bf(a) = 0
CHess f(a) positiv definit
D∂₁f(a) > 0
  • Antwort antippen: grün = richtig, rot = falsch, die richtige wird gezeigt.
  • Darunter steht die Erklärung, dann Weiter.
Gut für: Begriffe und Sätze erkennen.
2 · Richtig / Falsch

Eine Aussage, zwei Knöpfe

Aus partieller Differenzierbarkeit folgt Stetigkeit.
RichtigFalsch
Gegenbeispiel: 2x₁x₂/(x₁²+x₂²) in (0,0).
  • Schnell, ideal für zwischendurch.
  • Die Erklärung nennt oft ein Gegenbeispiel oder die typische Falle.
Gut für: Fallen und Voraussetzungen von Sätzen.
3 · Lückentext

Begriffe selbst eintippen

Der Vektor aller partiellen Ableitungen heißt Gradient, die Matrix der zweiten Ableitungen heißt Hesse → Hessematrix.
Lösung zeigenPrüfen
  • Groß-/Kleinschreibung, Leerzeichen und Umlaute sind egal.
  • Prüfen färbt die Lücken, bei Fehlern erscheint die Lösung. Lösung zeigen zählt als falsch.
Gut für: Definitionen auswendig können.
